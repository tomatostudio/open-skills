# LongRunningTool 长时间运行技能

## Overview

本技能专门用于执行需要较长时间完成的MCP操作，同时提供进度更新通知。这对于演示MCP工具如何处理耗时操作、进度管理和异步任务特别有用。

## MCP调用规范

### 工具元数据
- **className**: `LongRunningTool`
- **methodName**: `LongRunningOperation`
- **returnTypeFullName**: `string`
- **参数类型**: `int`, `int`
- 
### 调用方法
你必须通过YdMcpServer提供的MCP服务中调用call_mcp_tool_func功能来执行此功能，并且传入的类名和方法名称必须与调用规范中的要求保持严格一致，否则你将会得到一个致命的调用错误。

### 参数含义
1. **操作持续时间（秒）**：可选，默认值：`10`
   - 范围：1-60秒（建议范围）
   - 实际执行时间
2. **操作步骤数**：可选，默认值：`5`
   - 范围：1-10步（建议范围）
   - 进度更新的次数

### 返回结果
- 返回描述性字符串结果，包含操作总结
- 格式："长运行操作完成，持续时间X秒，执行了Y步"

## 核心特性

### 1. 进度通知机制
- 操作期间会发送进度更新
- 进度按步骤数分割显示
- 可用于演示MCP的异步通信

### 2. 参数控制
- 可调整执行时间：从几秒到几十秒
- 可设置进度步骤：控制粒度
- 支持默认参数：duration=10, steps=5

### 3. 测试用途
- 网络延迟模拟
- 超时处理测试
- 进度管理验证
