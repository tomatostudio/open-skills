# EchoTool 回显技能

## Overview

用于测试MCP工具调用的基本回显功能。接收字符串参数并返回格式化回显结果，验证基本调用流程和参数处理。

## MCP调用规范

### 工具元数据
- **className**: `EchoTool`
- **methodName**: `Echo`
- **returnTypeFullName**: `string`
- **参数类型**: `string`

### 调用方法
你必须通过YdMcpServer提供的MCP服务中调用call_mcp_tool_func功能来执行此功能，并且传入的类名和方法名称必须与调用规范中的要求保持严格一致，否则你将会得到一个致命的调用错误。

### 参数含义
1. 要回显的消息字符串

### 返回格式
```
Echo: {传入的消息}
```

## 核心特点

### 1. 简单验证
- 参数传递检查
- 字符串处理验证
- 基本调用管道测试

### 2. 无缓存机制
- 纯字符串返回
- 不涉及对象缓存
- 不需要GUID管理

### 3. 调试工具
- 连接状态验证
- 消息传递验证
- 异常处理测试

## 验证要点
1. **必须真实调用**：不能模拟回显逻辑
2. **参数类型**：必须是string类型
3. **返回格式**：必须是"Echo: "前缀
4. **调用顺序**：确保按顺序执行

## 错误处理
- 空字符串：正确处理空值
- null参数：异常情况处理
- 编码问题：特殊字符编码测试
