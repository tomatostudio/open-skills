# Sample Skill

This skill demonstrates how to process text input by converting it to uppercase.

## Usage Instructions

1. When you need to convert text to uppercase, use this skill
2. Provide the text that needs to be converted as input
3. The skill will return the uppercased version of the text

## Implementation Steps

1. Accept text input from the user
2. Apply uppercase transformation to the entire text
3. Return the transformed result

## Example

Input: "hello world"
Output: "HELLO WORLD"

## Notes

- This skill handles any UTF-8 text input
- Preserves whitespace and special characters
- Only alphabetic characters are affected by the case conversion
